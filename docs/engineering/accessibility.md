# Accessibility verification scope

Target: WCAG 2.2 Level AA across complete learner flows, including authentication, onboarding, lessons, tests, review, progress, reporting and access settings.

Verify semantic headings/landmarks; labels and error descriptions; keyboard-only use; visible/unobscured focus; status announcements; contrast without relying on color; text zoom/reflow; reduced motion; readable mobile touch targets; accessible sign-in and timing behavior. Preserve saved work around session expiry. Record essential-timing exceptions explicitly for exam simulation and provide appropriate verified accommodation configuration; do not assume every timer is exempt.

Combine automated browser checks with manual keyboard and screen-reader verification. Track actual criteria, page/flow, date, evidence and unresolved issues in the release record. This document establishes the target, not conformance; no scan alone establishes WCAG compliance.
